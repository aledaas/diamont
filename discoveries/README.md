# Descubrimientos

Este directorio conserva descubrimientos surgidos de la observación y el razonamiento conjunto.

Un descubrimiento no modifica por sí mismo la [Constitución](../docs/CONSTITUTION.md). Debe separar observaciones, interpretaciones, hipótesis y preguntas abiertas conforme al [protocolo de investigación](../research/protocols/research-protocol.md).
