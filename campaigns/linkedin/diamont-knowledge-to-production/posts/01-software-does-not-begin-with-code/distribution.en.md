# Distribution copy — Piece 01

Software doesn't begin with code.

It begins with an intention that does not yet have an executable form.

When we choose a framework, repository, or architecture before understanding the value we need to preserve, the system may work—and still move away from its purpose.

With AI agents producing software faster than ever, this is no longer a philosophical distinction. It is a problem of context, governance, and traceability.

In the first edition of **Knowledge → Production**, I explore why I am building DIAMONT around a simple principle:

> Intent precedes every production.

When do you consider a software project to have truly begun?
