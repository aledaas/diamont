# DIAMONT Campaigns

Este directorio conserva campañas públicas que materializan y comunican el avance de DIAMONT.

Una campaña no constituye la fuente normativa de DIAMONT ni reemplaza Crystals, Faces, discoveries o estudios. Su función es preservar intención comercial, narrativa, piezas publicadas, evidencia de recepción y decisiones editoriales para evitar que el aprendizaje de comunicación se pierda entre publicaciones o workers.
