# Software Factory

## Purpose

Preserve and grow engineering knowledge across production projects.

## Definition

The Software Factory is the project context in which DIAMONT transforms intention into executable knowledge and knowledge is treated as the principal productive asset.

## Responsibilities

- Own its crystallized knowledge.
- Reuse existing knowledge before creating new knowledge.
- Preserve evidence and learning across projects.

## Relationships

- Receives [Requirements](REQUIREMENT.md).
- Uses [MINA](MINA.md) to explore applicable knowledge.
- Produces through [Crystallization](CRYSTALLIZATION.md).

## Used By

- DIAMONT.
- Portfolio.
