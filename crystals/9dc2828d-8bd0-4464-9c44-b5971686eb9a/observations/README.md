# Observaciones pendientes

Este espacio registrará observaciones obtenidas al aplicar el Crystal, especialmente sobre:

- facilidad real de reutilización;
- ambigüedad entre dependency, import y genealogy;
- tamaño y suficiencia de Crystal Sets;
- duplicación de conocimiento;
- conflictos entre Crystals;
- resolución de identidades;
- costo de compilación;
- reutilización entre proyectos.

No contiene observaciones iniciales porque todavía no existe una implementación que produzca evidencia operativa.
