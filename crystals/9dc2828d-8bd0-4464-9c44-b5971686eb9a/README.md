## Intención

Permitir que conocimiento ya discutido, validado y cristalizado pueda reutilizarse de forma rápida, explícita, trazable y consistente entre proyectos.

## Resumen

Este Crystal establece la semántica mínima para resolver y reutilizar Crystals mediante identidad permanente. Distingue dependencia operativa, importación de conocimiento y genealogía intelectual; define el Crystal Set como conocimiento explícito utilizado por una intención, compilación o proyecto; y registra Registry y Resolver únicamente como evolución futura.
